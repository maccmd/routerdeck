# RouterDeck

Компактная тёмная и светлая тема для **OpenWrt LuCI** с отдельной панелью
мониторинга. Сохраняет штатные формы LuCI, управление доступом и Save & Apply.
Тема работает на обычных JavaScript и CSS.

[English](README.md) · [Установка](docs/installation.md) · [Навигация и окна](docs/navigation.md) · [Разработка](docs/development.md) · [Совместимость](docs/compatibility.md)

![Редактор интерфейса и маршруты рядом в OpenWrt 25.12.5](docs/screenshots/windows-dark.png)

Здесь описана текущая ветка **`main`** с изменениями после опубликованного
предварительного выпуска **v0.1.0**. Встроенных окон, описанных ниже, ещё нет в
пакетах этого выпуска: для них нужна сборка из текущих исходников.
См. [список изменений](CHANGELOG.md) и [описание v0.1.0](docs/releases/v0.1.0.md).

## Возможности

- Пакет **`luci-theme-routerdeck`**: две цветовые темы, мгновенное переключение,
  сохранение выбора в браузере, поиск по меню, мобильная навигация, оформление
  таблиц, форм и модальных окон, изменение ширины боковой панели. Название пункта
  меню открывает страницу, а значок справа — отдельное окно. Ссылки на объекты
  также открывают окна; их можно
  перемещать, менять в размере, сворачивать и привязывать к краям рабочей области.
  При открытии нового окна остальные автоматически подстраиваются по размеру.
  Меню строится по доступным страницам LuCI.
- Необязательный **`luci-app-routerdeck`**: uptime, средняя нагрузка, RAM,
  накопитель, WAN и его трафик, число соединений, интерфейсы, DHCP-аренды и
  базовое состояние интерфейсов WireGuard. Данные поступают из ubus/rpcd.
- **`luci-app-routerdeck-workspace`** оставлен для совместимости со старыми
  закладками. Отдельного пункта Workspace больше нет, окна входят в тему.
- Экспериментальный **`routerdeck-console`**, отдельный от LuCI: оконная
  консоль по адресу `/routerdeck/` по образцу настольных утилит для роутеров,
  которая работает с rpcd напрямую через `/ubus`. Quick Set, WiFi, интерфейсы
  (Ethernet, VLAN, WireGuard), мосты, PPP, адреса, маршруты и правила
  маршрутизации IPv4 и IPv6, firewall со списками адресов, DHCP и DHCPv6, DNS,
  UPnP, динамический DNS, очереди SQM, службы, меню System и журнал — живые
  списки объектов; Ping, Traceroute, Torch, Bandwidth Test, IP Scan, Netwatch,
  Wake on LAN и графики трафика — инструменты.
  Изменения применяются сразу, есть Undo/Redo и Safe Mode с автоматическим
  откатом. New Terminal — командная строка в стиле RouterOS над теми же
  объектами, New Shell — оболочка через ttyd.
  Подробности — в [описании консоли](docs/console.md) и [плане](docs/console-plan.ru.md).
  В сборку входит Preact (MIT).
- Bootstrap остаётся установленным. Установка RouterDeck не меняет выбранную
  тему; при удалении активной темы выполняется возврат на Bootstrap.

Версия 0.1 — **MVP, предварительный выпуск**. Оконный режим экспериментальный:
редактируйте и применяйте одну форму за раз. Процент загрузки CPU, температура,
рукопожатия WireGuard и определение присутствия клиентов пока не реализованы.
Недоступные значения
помечены явно; наличие DHCP-аренды не выдаётся за статус «онлайн».

## Работа с окнами

- Название пункта меню открывает обычную страницу. Значок окна справа открывает
  её рядом с текущей страницей.
- Название интерфейса, устройства или зоны межсетевого экрана открывает штатный
  редактор. Значок информации рядом показывает подробности. Редактор занимает
  всё окно, а Save и Dismiss закреплены под прокручиваемой формой.
- Новое окно размещается рядом с открытыми. Перетащите заголовок к краю или углу
  рабочей области для привязки. Разделитель между двумя колонками меняет их ширину.
- Левое меню остаётся доступным при разворачивании окон. Его правую границу можно
  перетаскивать мышкой; двойной щелчок возвращает исходную ширину.
- Редактируйте одну форму за раз. Save сохраняет отложенные изменения LuCI;
  для применения используется штатная команда **Save & Apply**.

Горячие клавиши, переходы между объектами и восстановление расположения описаны
в [руководстве по навигации и окнам](docs/navigation.md).

## Совместимость

| Система | Формат | Проверка |
| --- | --- | --- |
| OpenWrt 25.12.5, armsr/armv8 | `.apk` | Выпуск v0.1.0 и текущие окна проверены в QEMU |
| OpenWrt 24.10.8, armsr/armv8 | `.ipk` | Проверен v0.1.0; последние изменения окон ещё не перепроверены |
| FriendlyWrt / NanoPi R3S-LTS | Не подтверждена | Нужна проверка конкретной прошивки и устройства |

Подробные границы проверки перечислены в [отчёте](docs/testing.md).

## Установка

Для опубликованного v0.1.0 скачайте пакеты своего формата из
[Releases](https://github.com/maccmd/routerdeck/releases),
сверьте контрольные суммы и перенесите файлы в `/tmp` роутера.

```sh
# OpenWrt 25.12
apk update
apk add luci luci-theme-bootstrap
apk add --allow-untrusted /tmp/luci-theme-routerdeck-0.1.0-r1.apk
# Необязательная панель мониторинга
apk add --allow-untrusted /tmp/luci-app-routerdeck-0.1.0-r1.apk
# Только в v0.1.0: необязательная экспериментальная страница Workspace.
# В текущих исходниках пакет лишь перенаправляет старые закладки.
apk add --allow-untrusted /tmp/luci-app-routerdeck-workspace-0.1.0-r1.apk
```

Для новых встроенных окон [соберите пакеты из исходников](docs/development.md#checks-and-builds)
и следуйте [инструкции по установке](docs/installation.md).
Для 24.10 используйте `opkg update`, `opkg install luci luci-theme-bootstrap`,
затем `opkg install` и файлы
`luci-theme-routerdeck_0.1.0-r1_all.ipk`,
`luci-app-routerdeck_0.1.0-r1_all.ipk`.

Выберите **System → System → Language and Style → Design → RouterDeck** и
нажмите **Save & Apply**. Авторизация остаётся штатной. Сохраните доступ по SSH
на время смены темы.

## Возврат и удаление

```sh
uci set luci.main.mediaurlbase='/luci-static/bootstrap'
uci commit luci
apk del luci-app-routerdeck-workspace luci-app-routerdeck luci-theme-routerdeck
# В 24.10: opkg remove luci-app-routerdeck-workspace luci-app-routerdeck luci-theme-routerdeck
```

Уберите из команды имена расширений, которые не устанавливались. Обновите страницу.

## Локальная разработка

```sh
npm ci
npm run dev                 # http://127.0.0.1:5173
npx playwright install chromium webkit
./scripts/test.sh
./scripts/package.sh 25.12.5
./scripts/package.sh 24.10.8
```

Preview работает только с тестовыми данными и явно это показывает. Настоящая
интеграция проверяется отдельно в [OpenWrt VM](docs/development.md#openwrt-vm).
Доступ к VM открыт на `127.0.0.1`; сетевые настройки macOS менять не требуется.
