# RouterDeck 0.1.0 — preview release

These notes describe the published `v0.1.0` tag. Later changes on `main` are
listed under [Unreleased](../../CHANGELOG.md#unreleased); the LuCI theme
described here has since been replaced by RouterDeck Console.

An installable compact dark/light LuCI theme, with optional live monitoring and
an experimental multi-window workspace. Built using the official OpenWrt SDKs.

## Packages

| Package | Purpose |
| --- | --- |
| `luci-theme-routerdeck` | Theme, permitted dynamic navigation, native forms and responsive layout |
| `luci-app-routerdeck` | Optional live dashboard using existing ubus/rpcd data |
| `luci-app-routerdeck-workspace` | Optional isolated LuCI windows, saved geometry and form guards |

Choose APK for OpenWrt 25.12 and IPK for 24.10. Verify `SHA256SUMS-apk` or
`SHA256SUMS-ipk`, install the base theme, then choose RouterDeck under
**System → System → Language and Style → Design**. Optional extensions can be
installed independently. Bootstrap stays installed and is restored when the
selected RouterDeck theme is removed.

See [installation and recovery](https://github.com/maccmd/routerdeck/blob/v0.1.0/docs/installation.md)
and the [test report](https://github.com/maccmd/routerdeck/blob/v0.1.0/docs/testing.md).

## Scope

Validated on isolated ARM64 QEMU guests running upstream OpenWrt 25.12.5 and
24.10.8, with Chromium/WebKit desktop and mobile checks. This is not hardware
certification for FriendlyWrt or NanoPi R3S-LTS.

Workspace is experimental: edit/apply one form at a time because UCI staging is
shared by the session. Other windows must reload after an apply. Use normal LuCI
for third-party applications with custom save controls.

CPU is load average, DHCP entries are leases, and WireGuard status refers to the
interface rather than peer reachability. Thermal sensors, CPU usage percentage
and peer handshake times are unavailable in this version. Native firmware
flashing, real PPPoE/VPN connectivity and physical peripherals were not exercised.

Apache-2.0. No proprietary MikroTik artwork or frontend framework is bundled.
